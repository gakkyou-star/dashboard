# 探究学習アンケート分析モジュール

「高校魅力化評価」アンケート結果を、鹿追町教育大綱（令和5年4月）の政策との対応関係が
分かる形で可視化するモジュール。ダッシュボード本体（学校概況〜入寮者情報）に
「探究学習アンケート」タブとして統合されている。

表示内容：4資質の伸び（棒グラフ）／層×資質マトリクス（ヒートマップ、セルクリックで個別設問を展開）／
伸び幅ランキング（自校 前年度比 TOP5・WORST5）／県平均・全国平均との差分バブルチャート（トグル切替）／
アントレプレナーシップ関連指標／多様性・地域みらい留学の影響（No.22/23・No.69/70の3年推移）／
要強化項目（大綱の対応政策・関連する強み項目を併記）。

## 次年度以降の更新手順（3ステップ）

1. **Excelを差し替える**
   `高校/高校魅力化評価/` フォルダに、新しいレポートExcel
  （`北海道鹿追高等学校_20XX年度_レポート（生徒1回目回答）_全校.xlsx` 等）を追加する。
   同フォルダ内で最も更新日時が新しいファイルが自動的に採用される（旧ファイルは削除不要）。

2. **集計スクリプトを再実行する**
   ```bash
   cd ダッシュボード
   python3 scripts/aggregate_kokorozashi_survey.py
   ```
   `output/kokorozashi_survey_2026_raw.json`・`kokorozashi_survey_2026_tagged.json`・
   `kokorozashi_survey_2026_tagged.js` が再生成される。

3. **`index.html` をブラウザで開いて確認する**
   グラフ・要強化項目・アントレプレナーシップ指標が新しい年度の数値に更新されていることを確認する。

## ロジックを調整したい場合

`scripts/aggregate_kokorozashi_survey.py` の冒頭付近にある定数をまとめて編集する。

| 定数 | 内容 |
|---|---|
| `WEAK_THRESHOLD_PT` | 「要強化項目」として抽出する全国トレンド比の閾値（既定 -3.0pt） |
| `PRIORITY_WEAK_NOS` | 赤系で最優先強調表示する設問番号（魅力化・定住目的に直結する項目） |
| `ENTREPRENEURSHIP_NOS` | アントレプレナーシップ特集セクションで扱う設問番号（強み／課題） |
| `WELLBEING_SELF_PERCEPTION_KEYWORDS` | 自己認識区分のうちウェルビーイングタグも付与するキーワード |
| `RELATED_STRENGTH_TOP_N` / `RELATED_STRENGTH_MIN_TREND` | 要強化項目カードに添える「関連して伸びている項目」の抽出条件 |
| `DIVERSITY_POLICY_TAGS`（`diversity_impact`ブロック内） | 「多様性・地域みらい留学の影響」セクション専用の政策タグ（政策6/10/5固定）。対象設問番号（22/23/69/70）も同ブロック内で直接指定 |

これら設問番号・閾値は大綱との対応関係やアンケート設計に基づく判断のため、
年度が変わっても対象の設問構成が同じであれば変更不要。設問が追加・削除された場合のみ見直す。

## ファイル構成

```
ダッシュボード/
├── scripts/
│   └── aggregate_kokorozashi_survey.py   # 集計・タグ付けスクリプト
├── output/
│   ├── kokorozashi_survey_2026_raw.json     # Excelの機械的な書き起こし
│   ├── kokorozashi_survey_2026_tagged.json  # 政策タグ・弱点判定を付与した加工データ
│   └── kokorozashi_survey_2026_tagged.js    # 上記をwindow変数として埋め込んだ版（file://対応）
├── kokorozashi.js                        # 表示ロジック（index.htmlから読み込み）
└── index.html / style.css                # 「探究学習アンケート」タブとして統合済み
```

既存ダッシュボード（`scripts/aggregate.py` → `output/dashboard_data.js` → `script.js`）とは
独立した集計・表示パイプラインとして分離してあるため、双方が互いに影響しない。

## 内部向け運用メモ（管理者向け・非公開）

⚠️ 以下はダッシュボード（生徒・保護者向け公開画面）には表示していない、
教育委員会・学校事務局向けの運用メモ。公開画面側の注記は index.html
「探究学習アンケート」タブ最下部の脚注（データの限界の明記）を参照。

- **現状の制約**: 本アンケートは学校全体の集計値のみが提供されており、
  学年別・個人別の内訳は含まれていない。そのため「探究性は伸びているが
  学年間でばらつきがあるか」といった深掘り分析は、現行データからは行えない。
- **今後の検討事項**: 次回以降のアンケート実施時に、集計元データを
  学年別に取得できるよう依頼できないか検討の余地がある。学年別データが
  得られれば、本モジュールの集計スクリプト（`aggregate_kokorozashi_survey.py`）を
  学年ディメンションで拡張し、学年別ヒートマップ・ランキング等を追加することは
  技術的には容易（既存の集計→タグ付けの分離構造をそのまま踏襲できる）。
- 本メモは実装時点（本追記対応時）の判断であり、次年度以降にアンケート仕様が
  変わった場合は内容を更新すること。
- **「多様性・地域みらい留学の影響」セクションについて**: 現行アンケートには
  「地域みらい留学生か地元生か」という生徒の属性区分が含まれていないため、
  No.22/23（違いを認め合う文化）・No.69/70（地域とのつながり）の伸びが
  同制度によるものか、探究学習の充実など他の施策と重なった結果かを
  切り分けられない。公開画面側でも相関の提示にとどめ、因果関係を断定する
  表現は避けている（`data_limitations`に明記）。次年度以降、アンケートに
  当該属性区分が追加された場合は、`aggregate_kokorozashi_survey.py`の
  `diversity_impact`ブロックを属性別集計に拡張し、より踏み込んだ分析
  （例: 地域みらい留学生と地元生での伸び幅比較）を行うこと。
